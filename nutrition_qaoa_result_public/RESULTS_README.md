# Completed nutrition QAOA run

`start_here.ipynb` is the executed notebook. The full run is under
`outputs/runs/20261014T103117_956650Z/`, including QAOA trial data, summaries,
plots, progress records, and environment diagnostics. The run completed on CPU.

This folder also contains the model, experiment code, tests, requirements, and
food data used by the notebook. When opened from this folder, the notebook can
use these files directly; the upload archive is not needed. Running all cells
again creates a new run rather than reproducing the historical output folder.

The publication copy removes the original home-directory username, Slurm
account, cluster hostname, and queue job/node identifiers from text diagnostics
and notebook outputs. All published CSV files are byte-for-byte identical to
the downloaded results. Numeric values in JSON, JSONL, and notebook files were
checked to remain unchanged. The downloaded originals are retained locally and
are not part of this publication folder.
